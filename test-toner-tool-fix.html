🎨 颜色深浅调节工具测试 - 变淡模式修复

修复前后算法对比

🔧 修复前的问题算法：

// 旧算法（有问题）
const brightnessBoost = (255 - Math.max(r, g, b)) * adjustedIntensity
newR = Math.min(255, r + brightnessBoost * (r / 255))
newG = Math.min(255, g + brightnessBoost * (g / 255))
newB = Math.min(255, b + brightnessBoost * (b / 255))

问题：使用最大颜色值计算增量，导致效果微弱且不对称

✅ 修复后的正确算法：

// 新算法（修复后）
newR = Math.min(255, r + (255 - r) * adjustedIntensity)
newG = Math.min(255, g + (255 - g) * adjustedIntensity)
newB = Math.min(255, b + (255 - b) * adjustedIntensity)

优势：与加深算法对称，每个颜色通道独立向255（白色）增量
